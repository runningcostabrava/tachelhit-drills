# ADR 0000: Plantilla

- **Estat:** plantilla (copia-la, no la toquis)
- **Data:** AAAA-MM-DD
- **Decideix:** qui
- **Issue:** #

## El problema

Què ens ha passat perquè calgui decidir res. Fets, no intencions: què vam veure, on, i què no
funcionava. Si hi ha una mesura, va aquí.

## Les opcions

Cada opció amb el que té a favor i el que té en contra, inclosa la de no fer res.

| opció | a favor | en contra |
|---|---|---|
| | | |

## La decisió

Què fem, dit en una frase. I per què aquesta i no les altres.

## Què en ve al darrere

El que això ens obliga a fer o deixar de fer, ara i més endavant. També el que empitjora: una
decisió sense cap inconvenient normalment vol dir que no s'ha mirat prou.
